## 8/19～21（3日間 JS 授業）の位置づけ

**認識：本契約の講師業務の延長として妥当**

- 甲から発注された**講師業務**（受講生向け JS 授業）そのもの
- 育成講師（出野・辻野）の聴講・TA 同行は、モデル授業として**当該講師業務の実施方法の一部**と解釈できる

## 8/25（育成講師向け座学＋実技研修）の位置づけ

**ステータス（2026-07-06）：不実施（白紙）** … 報酬面で折り合いがつかず。以下は協議時点の整理として残す。

**認識：契約書上の「講師業務」とは別枠の業務として妥当**

### 別枠とみなせる理由

1. **対象者が異なる** … 受講生ではなく、育成講師2名向け
2. **目的が異なる** … 授業実施ではなく、講師育成・カリキュラム再現のための研修
3. **日程・形式が異なる** … 3日間授業終了後の別日、約4時間の座学＋実技
4. **報酬体系が異なる** … 先方打診は**会議費**（＋資料作成2H）。講師コマ単金ではない
5. **契約第1条2項** … 内容・実施方法の追加は**甲乙協議のうえ改めて決定**が必要。8/25 はこの「追加業務」に該当

### 結論

- **8/25 は、既存の講師業務委託の自動的な範囲内とは言い切れない**
- ただし契約外だから**無報酬**という意味ではなく、**別発注・別条件（会議費等）での合意が必要な追加業務**
- 先方が「会議費支給＋2H」と明示している点は、**別業務として扱う双方認識**と整合的
