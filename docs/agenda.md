# 職業訓練「グラフィック・Webデザイナー養成科」におけるJavaScriptの授業(8/19,20,21)のカリキュラム策定

## 受講生情報
- グラフィック及びWebデザイナーへのキャリアチェンジを目指す職業訓練生。
- スキルレベルは現時点で不明だが、プログラミング未経験者であることを前提とする。
- JS の授業前までに基本的な HTML/CSS については学習済みの予定。習熟度は低めの前提とする。
- 本クラスはプログラミング科ではなく Webデザイナー向けのため、複雑なUIやロジックの実装は目標に含めない。

## 着地点（カリキュラムのゴール）

静的な1ページサイト（ポートフォリオ）に、案件でよく使われる動きを **3パターン** 付ける。Profile内のSkillsは静的コンテンツとして HTML/CSS のみで掲載する。

| 優先度 | UI | 概要 |
|--------|-----|------|
| 必須 | ドロワーメニュー | 768px未満でハンバーガー開閉。クラスの付け外し。768px以上は横並びナビ |
| 必須 | モーダル（画像拡大） | Works カードクリック → `<dialog>` で画像拡大（`src` コピー） |
| ライブラリ1つ | カルーセル（Swiper） | CDN 読み込み＋数行の初期化。自作はしない |

※ アコーディオン・FAQ は**不採用**（ポートフォリオの UX・文脈に合わない。詳細は `docs/design_brief.md`）。

### 対象外（講師デモに留めるか省略）
- タブメニュー
- アコーディオン UI
- `aria-*` 属性（JS 実装に集中するため教材では付けない。口頭で触れる程度）
- 配列データからの HTML 動的生成・フィルタリング・再描画（プログラミング寄りすぎる）
- イベント委譲（イベントバブリング、`event.target` の判別など）。口頭または短いデモで「こう書く方法もある」程度に留める

### jQuery の立ち位置

**紹介のみ。最終課題・演習の実装には使わない。**

| 項目 | 内容 |
|------|------|
| 位置づけ | 現場で見かける用語・書き方の**概要説明**（レガシーサイト・古いテンプレート文脈） |
| 実施タイミング | **3日目・4コマ目**（約10〜15分のデモ＋説明。個人実装はしない） |
| 最終課題との関係 | `materials/finish/portfolio/` および各 `steps/*/portfolio/` は **バニラ JS のみ**。jQuery は読み込まない |
| 着地点 | 「`$` や `$(function(){})` を見たことがある」「バニラ JS の `addEventListener` と役割が似ている」とわかれば十分 |

**やること（紹介の範囲）**

- 「昔からよく使われた JS の書き方」として位置づける
- `$('.menu-btn').on('click', function(){ ... })` を**見本で見せる**（バニラ JS のドロワーコードと並べて対比）
- `$(function(){ ... })` ＝ ページ読み込み後に実行する、という意味だけ伝える
- 新規制作では Vanilla JS やフレームワークが主流であることを一言添える

**やらないこと**

- jQuery でドロワー・モーダル等を**実装させる**
- セレクタ詳細、`.each()`、AJAX、プラグインの自作・深い設定
- 構文の暗記や演習課題

※ 初版目標の「jQuery の基本構文がわかる」は、本クラスでは **上記の概要レベル** で充足するものとする。

### バニラJSで扱う範囲
- `querySelector` / `addEventListener`
- `classList.add` / `remove` / `toggle`
- モーダル：`showModal()` / `close()`（`<dialog>`）。画像の `src` / `alt` をカード内 `img` からコピー
- Works 複数カード：`querySelectorAll` + `forEach`（**3日目**・進捗に応じて。1〜2日目では扱わない）
- `data-*` 属性・配列・`innerHTML` による動的生成は着地点に含めない

### 複数要素へのイベント登録（Works・3日目）

Works カードが複数あるため、1日目の「要素1つ＋クリック」を発展させる。アコーディオンではなく**全カードに同じモーダル処理**を付ける。

| 方式 | 扱い | 理由 |
|------|------|------|
| `querySelectorAll` + `forEach` | **教える（3日目）** | 各カードの `img.src` を dialog にコピーして開く |
| 配列 / `data-*` | 対象外 | カード内の `img` から `src` を読めば足りる |
| イベント委譲 | 参考程度 | 説明コストが高い |

運用上は、決まり文句としてパターンを配布し、class 名の変更など一部を自分で直す形から始める。全員が自力で書けることは目標にしない。

## 目標

### 受講生向け（着地点の言い換え）
- 静的な1ページサイトに、ドロワーメニュー・モーダル（画像拡大）を実装できる（2日目）。
- 3日目に、Works 全カードへの `forEach` と Swiper を**進捗に応じて**追加できる。
- 必要に応じて、カルーセルをライブラリ（Swiper）で追加できる。
- jQuery は概要のみ知り、本課題の実装はバニラ JS で行う。
- 「クリックで見た目が変わる」仕組みを、自分のデザインに当てはめられる。

### 到達レベルの切り分け
| レベル | 到達イメージ | 目安 |
|--------|--------------|------|
| A（最低ライン） | 完成例を動かし、テキスト・色・画像を差し替えられる。コードの役割をざっくり説明できる | 全員 |
| B（本来の着地点） | ドロワー＋モーダル（1カードで画像拡大）を組み込める（2日目） | 約1/3 |

※「全員が3動き全部を自力完成」は目標にしない。

### スケジュール設計上の方針

- **初日3コマ目が分水嶺**：1〜2コマ目は通例どおり概念導入に充て、**3コマ目で必ず Console に手を動かす**。
- **毎日最終コマは実装・まとめ**：座学が続くと集中力が切れるため、各日の6コマ目（または5〜6コマ目）はワーク中心にする。
- **2日目はモーダル1本**：Bレベル到達（ドロワー＋モーダル）を優先し、負荷を分散（案A）。
- **3日目の Works 全カード（forEach）は可変**：進捗に応じてデモのみ〜個人ワークまで。Swiper・仕上げを優先。
- **同じ型の反復**：1日目で確立した「取得→クリック→class」の型を、2日目以降は新しい UI 名を当てはめるだけに見せる。
- **ミニ練習 → 本課題**：手を動かすコマは `materials/practice/` で導入し、その日の着地点は `start/portfolio` で実装する（詳細は `materials/practice.md`）。
- **TA の役割**：4コマ目以降は巡回・個別フォローが主。セレクタの typo、JS ファイルの読み込み忘れ、`script` の位置など定型的なつまずきに備える。
